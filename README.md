# Sift

Removes the hidden files macOS litters across your drives, and makes Finder view modes consistent.

**[Download Sift for Mac](https://github.com/livenetdev/sift/releases/latest/download/Sift.dmg)**
· macOS 13 or later · free, from Livenet

## Install

1. Open `Sift.dmg` and drag Sift into Applications.
2. Open Sift from Applications.

If macOS says it can't verify the developer, open **System Settings › Privacy & Security** and click **Open Anyway**.

## Updating

Download again from the link above. Only the newest version is kept here.
